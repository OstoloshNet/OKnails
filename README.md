# OKnails

Сайт майстра манікюру та педикюру OKnails (Остолош Катерина, с. Кушниця).

Статичний односторінковий сайт: `index.html` + логотипи `logo.jpg`, `logo-mark.jpg`. Збірка не потрібна.

## Як редагувати

Усі дані (послуги, ціни, графік, контакти, реквізити оплати, FAQ) зібрані в одному об'єкті `CONFIG` у `index.html`, у блоці «НАЛАШТУВАННЯ».

- `showDraft: false` ховає всі умовні позиції прайсу (з позначкою «Умовно»).
- `pay.card` / `pay.iban`: заповніть, щоб показати реквізити на сайті.
- Години роботи вказуються за київським часом.

## Публікація

GitHub Pages: Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`.
